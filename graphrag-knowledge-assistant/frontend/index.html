Hybrid GraphRAG Architectural Workflow

GraphRAG overcomes the limitations of naive vector search by unifying dense semantic embeddings with relational knowledge graph traversals.

1. Ingestion & Graphing Documents are parsed into chunks and embedded in ChromaDB while simultaneously extracting entities and relations into a NetworkX graph.
2. Dual-Mode Retrieval User queries trigger dense semantic cosine search and k-hop relational graph traversals in parallel.
3. Reciprocal Rank Fusion Chunks mentioning retrieved graph entities receive provenance boost scoring to guarantee structural relevance.
4. Grounded Synthesis The dual-engine LLM generates answers derivationally restricted to retrieved passages and factual triples with inline citations.
